## Troubleshooting Guide

### Nothing happens when I try to download

Test the network connection, then reopen the download page and try again. If the problem remains, look through the repository for a newer build or relevant usage notes.

### Required files cannot be reached

Make sure the system has network access and that a firewall, permission, or other local restriction is not preventing the downloader from connecting. The source may also be temporarily unavailable, so trying again later can help.

### The downloaded mods are missing in Minecraft

First confirm that the downloader completed without interruption. Then consult the project instructions to verify the expected file location and any required setup steps.

### Downloaded files cannot be saved

Inspect the permissions on the target directory. Use a folder where the current user is allowed to create and modify files.

### An earlier download interferes with a new attempt

Examine the files left by the previous run and move or delete incomplete items before retrying. Back up anything important before changing the local files.
